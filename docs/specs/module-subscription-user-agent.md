## 2. 目标与范围

### 背景

部分订阅转换服务会根据请求的 `User-Agent` 返回不同的节点入口。实际验证中，同一个 xusx 订阅使用 `ClashMeta` 返回不可达的 `ff.xs-us.net`，使用 `clash-verge/v2.4.5` 返回可用的 `11.xs-us.net`。1.11.7 已把 UA 固定为 `clash-verge/v2.4.5`，但没有用户可配置入口，无法适配其他转换服务或供应商。

### 目标

- 增加全局 mihomo 节点订阅 UA 设置，默认 `clash-verge/v2.4.5`。
- 允许每个节点订阅单独覆盖 UA；留空表示继承全局。
- 订阅地址和聚合 provider 下载都使用该订阅最终生效的 UA。
- WebUI 同时提供全局设置和订阅级设置，使用预设加自定义输入。
- 保持现有订阅清单格式和 sing-box 行为不变。

### 非目标

- 不按 provider 单独设置 UA。
- 不改变 sing-box 订阅的 `sing-box` UA。
- 不自动探测、轮换或回退 UA。
- 不在保存 UA 设置时立即联网刷新订阅。
- 不实现 UA 对应节点的可用性自动校验。

## 4. 行为要求与约束

### R-001：全局订阅 UA 设置

- 参与者或触发方：设置页、`settings get/apply`、`box.tool upsubs`
- 前置条件与输入：`settings.json` 中存在 `subscription_user_agent`
- 必须满足的行为：
  - 默认值为 `clash-verge/v2.4.5`
  - 值是非空字符串，最长 255 字符
  - 拒绝 CR、LF 和其他控制字符
  - 缺失时使用默认值，不因旧配置缺少该键而失败
  - 仅用于 mihomo 节点订阅下载
- 输出或状态变化：设置页显示“订阅 User-Agent”，runtime 提供 `subscription_user_agent`
- 边界与失败行为：非法值返回 `E_VALIDATION`，不写入 settings 或 runtime

### R-002：按订阅覆盖 UA

- 参与者或触发方：订阅添加/编辑表单、`sub add/set/get --json`
- 前置条件与输入：订阅存在；请求可携带可选 UA
- 必须满足的行为：
  - 空 UA 表示继承全局
  - 非空 UA 保存为该订阅的覆盖值
  - 覆盖值按订阅持久化，不使用 `名字|URL|enabled` 的第四列
  - 订阅重命名时覆盖值随之迁移
  - 删除订阅时清理覆盖值
  - `sub get --json` 返回原始覆盖值 `user_agent` 和最终值 `user_agent_effective`
- 输出或状态变化：编辑表单显示该订阅的原始覆盖值
- 边界与失败行为：非法 UA 返回 `E_VALIDATION`；空字符串是合法输入，表示清除覆盖

### R-003：UA 生效顺序

- 参与者或触发方：`box.tool upsubs`
- 前置条件与输入：一次 mihomo 订阅更新
- 必须满足的行为：
  - 订阅覆盖值非空时使用覆盖值
  - 否则使用全局 `subscription_user_agent`
  - 全局值缺失时使用 `clash-verge/v2.4.5`
  - 同一订阅的转换地址下载和其聚合 provider 下载使用同一个最终值
- 输出或状态变化：请求头 `User-Agent` 等于最终值
- 边界与失败行为：不得把 UI 显示值或原始覆盖值直接当作最终值

### R-004：下载失败处理

- 参与者或触发方：订阅或 provider 下载失败
- 前置条件与输入：HTTP 错误、空文件、解析失败或 `subscription_keep_last_good=true`
- 必须满足的行为：
  - 保留该订阅上一次可用的 provider 文件和主配置
  - 不自动改用其他 UA
  - 返回失败或部分成功状态
  - 错误信息不回显订阅 token
- 输出或状态变化：用户可在下次修改 UA 后重试
- 边界与失败行为：首次下载且没有旧文件时，不生成空 provider 覆盖配置

### R-005：WebUI 输入与展示

- 参与者或触发方：设置页、节点订阅添加/编辑表单
- 前置条件与输入：用户编辑全局或订阅级 UA
- 必须满足的行为：
  - 提供 `clash-verge/v2.4.5`、`clash.meta/1.19.20`、`Clash`、`mihomo/1.19.20`、`ClashforWindows/0.20.39` 预设
  - 允许通过“自定义”输入任意值
  - 订阅级空值存储为继承全局，界面通过显式的“跟随全局”选项表达
  - 设置页提示“仅影响 mihomo 节点订阅”和“下次更新订阅生效”
  - 保存 UA 不触发订阅下载
- 输出或状态变化：设置和订阅详情持久化；订阅列表不新增独立 UA 列
- 边界与失败行为：前端校验拒绝空全局值和换行；后端仍做最终校验

### R-006：仅作用于 mihomo

- 参与者或触发方：mihomo 订阅、provider 更新任务
- 前置条件与输入：存在 mihomo 订阅或 provider
- 必须满足的行为：
  - 普通 mihomo 订阅和聚合 provider 使用 R-003 的最终值
  - 现有 `subscriptions.list` 前三列语义不变
  - 不读取或写入已移除的 sing-box 配置
- 输出或状态变化：无
- 边界与失败行为：不得因 UA 设置改变 mihomo 之外的任何核心行为

### R-007：User-Agent 选择器交互

- 参与者或触发方：设置页、订阅添加/编辑表单
- 前置条件与输入：用户选择全局或订阅级 User-Agent
- 必须满足的行为：
  - 使用原生下拉选择器承载预设值，不使用 `datalist` 或可编辑建议输入框
  - 选择预设值时不得聚焦文本输入框，不得唤起输入法
  - 只有选择“自定义”后才显示独立文本输入框
  - 订阅级下拉必须提供显式的“跟随全局”选项；该选项清空覆盖值
  - 从自定义切回预设或“跟随全局”时，隐藏自定义输入框
  - 自定义值仍使用后端最终校验
- 输出或状态变化：预设选择只改变值，不打开键盘；自定义输入可正常编辑
- 边界与失败行为：自定义值为空时阻止保存并提示；不得用留空输入框代替“跟随全局”

### 相关约束

- UA 值可能包含空格、斜杠和括号，不能做 URL 编码或 shell 插值拼接。
- 日志只输出最终 UA；不输出订阅 URL 中的 token。
- 覆盖值文件权限为 `0600`。
- 保持现有 API 包络和 CLI 向后兼容。

## 5. 关键决定

### D-001：全局默认加按订阅覆盖

- 状态：已确认
- 结论：全局设置提供默认值；每个节点订阅可覆盖。
- 理由：多数订阅只需统一值，特殊供应商仍可单独适配。
- 考虑过的备选：仅全局；仅按订阅。
- 未采用原因：仅全局无法处理差异；仅按订阅缺少统一入口。
- 影响范围：R-001、R-002、R-003、R-005

### D-002：默认 UA 保持已验证值

- 状态：已确认
- 结论：默认值为 `clash-verge/v2.4.5`。
- 理由：与 OpenClash 一致，已实际验证 xusx 可用；保持 1.11.7 修复效果。
- 考虑过的备选：`ClashMeta`；`mihomo`；留空。
- 未采用原因：`ClashMeta` 会重新拿到不可达入口；`mihomo` 未验证；留空会破坏升级后的可用性。
- 影响范围：R-001、R-003

### D-003：覆盖值使用独立 sidecar

- 状态：委托范围内决定
- 结论：按安全订阅名保存到 `mihomo/subscriptions.ua/` 下的独立文件，不使用 `subscriptions.list` 第四列。
- 理由：UA 可能含空格、斜杠等字符，独立文件避免分隔符和转义；现有订阅格式保持兼容。
- 考虑过的备选：扩展 `subscriptions.list` 第四列；单个映射文件。
- 未采用原因：分隔符和重命名处理更脆弱；映射文件需要额外解析。
- 影响范围：R-002、R-003、R-006

### D-004：下次更新生效

- 状态：已确认
- 结论：保存 UA 只写配置；下一次订阅更新时使用新值。
- 理由：避免保存设置产生隐式网络请求和节点切换。
- 考虑过的备选：保存后立即刷新。
- 未采用原因：行为不可预测，可能中断当前代理。
- 影响范围：R-005

### D-005：失败不自动回退

- 状态：已确认
- 结论：下载失败时保留上次可用配置并报错，不自动改用其他 UA。
- 理由：避免用户选择与实际行为不一致，便于定位问题。
- 考虑过的备选：自动回退全局；自动回退默认。
- 未采用原因：会掩盖 UA 配置错误。
- 影响范围：R-004

### D-006：选择与编辑分离

- 状态：已确认
- 结论：User-Agent 使用“下拉预设 + 条件自定义输入框”，订阅级提供“跟随全局”选项。
- 理由：`datalist` 在 Android WebView 中会同时聚焦输入框并弹出建议层和输入法，预设选择与自由编辑发生冲突。
- 考虑过的备选：保留 datalist；常驻输入框加预设按钮；仅自由文本。
- 未采用原因：无法消除叠层和误触，或页面过重。
- 影响范围：R-005、R-007、AC-006、AC-008

## 6. 验收标准

### AC-001：默认全局 UA

- 对应规则：R-001

- 操作或输入：读取设置并更新订阅
- 预期结果：`subscription_user_agent` 为 `clash-verge/v2.4.5`；订阅请求使用该 UA
- 验证状态：通过

- 预期结果：前者最终值为 `ClashMeta`；后者最终值为全局值；两者下载请求头分别正确

### AC-004：非法 UA 拒绝

- 对应规则：R-001、R-002
- 前置条件：提交含换行或空全局值
- 操作或输入：保存设置或订阅

- 验证状态：通过

### AC-005：失败保留上次可用

- 对应规则：R-004

- 操作或输入：更新订阅
- 预期结果：旧 provider 文件和主配置保留；返回失败；日志无 token
- 验证状态：通过

- 对应规则：R-005、R-007
- 前置条件：打开设置页和订阅编辑表单

## 7. 未决问题与假设

### Q-001：自定义 UA 的节点可用性

- 类型：暂用假设
- 内容：用户选择的 UA 可能返回不可达节点，本规格只保证按值发送，不保证节点可用。
- 影响范围：R-004、R-005
- 是否阻塞：否
- 决定或验证方式：失败时保留上次可用并提示；后续可另做可用性校验。

## 8. 技术设计

### 8.1 数据与模块

- `settings.json` 新增字符串 `subscription_user_agent`，由 `settings.schema.json`、`settings.default.json` 和 `settings.base.sh` 提供默认值与运行时变量。
- 每订阅覆盖值保存在 `mihomo/subscriptions.ua/<安全订阅名>.ua`，内容为单行 UA，缺失或空文件表示继承。
- `box.tool` 增加读取、写入、重命名、删除覆盖值以及计算最终 UA 的函数。

### 8.2 接口

- `sub add <url> [name] [ua]`：第三参数可选；空值表示继承。
- `sub set <old> <new> <url> [ua]`：省略 UA 时保留原覆盖值；显式空字符串表示清除覆盖。
- `sub get --json` 增加 `user_agent` 和 `user_agent_effective`。
- `sub list --json` 增加 `user_agent_effective`，供展示或调试；不改变现有字段。
- 设置页新增全局字段；订阅添加/编辑表单新增可选 UA 字段。
- 两者均使用原生下拉选择器；预设和自定义输入框分离，不使用 `datalist`。

### 8.3 下载链路

- `upsubs` 为每个订阅计算最终 UA。
- 转换地址下载使用最终 UA。
- `sub_update_aggregate` 接收最终 UA，并用它下载每个 provider。
- sing-box 分支保持原有 `sing-box` UA。

### 8.4 校验

- 非空全局 UA：长度 1–255，不含 CR/LF 和控制字符。
- 订阅覆盖值：空字符串允许；非空时同上。
- 前端同步校验，后端作为最终权威。
